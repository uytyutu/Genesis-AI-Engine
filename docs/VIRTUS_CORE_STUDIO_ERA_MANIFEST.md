## Agency Operating System

Virtus Core is the **operating system of a digital agency**.

Roles need not all be separate code modules.  
**Every generation must answer this chain of questions:**

```text
CEO                    → Does this strengthen the client's business presence?
Creative Director      → Is the creative direction clear and ownable?
Brand Strategist       → What is this brand's personality — and why?
Marketing Strategist   → What should the stranger feel and do?
UX Researcher          → Is the path human, calm, and credible?
Art Director           → Does every scene have a visual center?
Typography Director    → Does type carry character and voice?
Color Director         → Does color create the right emotion?
Motion Director        → Does every motion have meaning?
Frontend Architect     → Is the craft export clean and resilient?
Accessibility Specialist → Can everyone use this with dignity?
Performance Engineer   → Does beauty stay fast?
QA Designer            → Would a studio ship this without shame?
Owner Review           → "Да. Я бы купил такой сайт."
```

## Digital Signature

Sites must be **different**.  
Craft level must be **recognizable**.

Not a template. Not the same colors.  
A studio handwriting of quality:

- attention to detail
- meaningful motion
- strong typography
- harmonious spacing
- considered interactive states
- coherent interaction sequences

Stranger reaction to aim for:

> "I don't know who made this — but the work is clearly strong."

That is the **Digital Signature of Virtus Core**.

## Law №1 — Quality ratchet

> Each new project must not be worse than the previous best.  
> Template / constructor / below studio → **REBUILD**.

---

## Law №2 — Reality Over Architecture

> **Any new idea must first become visible to the client.**

The client never sees Manifest, Agency OS, Taste Engine, DNA, Observatory, or Memory.  
The client sees only:

1. the first screen  
2. time to result  
3. quality of result  

If those three do not create emotion, no Manifest saves the product.

For every new Director, Engine, Rule, or Memory ask:

> **"What changes in the client's first impression?"**

If the answer is:

> "Nothing yet — but architecture is better"

then **the work is unfinished**. Stop building invisible layers. Finish the visible result.

## Control set (product review, not code review)

After a significant Factory change, generate a **control set** across niches, e.g.:

- Psychology  
- Dental  
- Restaurant  
- Auto service  
- Law  
- Electronics store  

Compare as product — not as code:

- six different brands?  
- different studio decisions?  
- niche readable in 3–5 seconds?  
- Business ≥ Virtus Core `/site` bar?  
- Premium clearly above Business?  

Any fail → **REBUILD**.

## Owner = Creative Critique

Owner does not only say Yes / No.  
Owner scores what the eyes feel:

- Hero · Typography · Motion · Brand · Composition · Trust · Store  

FAIL must carry **why**. Experience Memory learns patterns from scores over time.

## Reality Benchmark — FAIL

Owner verdict on the 18-demo control set: **FAIL**.  
Studio Era is **not yet achieved**. Direction is correct.

### Commercial Owner FAIL (2026)

Not CSS. Not Hero. Philosophy: niche template with swapped labels.

**Final question:** If told “this company is 5 years old,” would a stranger believe it?  
If no → Generation FAIL.

**Goal:** Business Generation — invent a living company (name, legend, mission, team, 8–15 priced services, FAQ, **demo-labeled** reviews), then export site/store.

Module: `app/factory/company_fabrication.py`

While FAIL: no new product features — generation quality only.

## Studio Era meaning

Studio Era is not a rename.  
It is the shift from **page generation** to **Creative Identity Generation** —
designing the digital identity of a business.

Virtus Core is the first **AI Digital Studio** aiming to cover:

- brand strategist · art director · UX · web design · motion · frontend

Until demos look like that team's work, Goal B stays open.

Compete with constructors → lose.  
Compete with world-class digital studios on result quality → win.
